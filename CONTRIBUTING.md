# Contributing

Thanks for your interest in `molecule-viewer`!

This is a hobby project focused on C++, OpenGL, and molecular visualization. Contributions, ideas, bug reports, and constructive feedback are welcome.

There is no expectation that anyone contributes regularly. This project is developed in my spare time, so responses and reviews may take a while.

## How to contribute

### Report a bug

If you find a bug, please open an issue and include as much relevant information as possible:

- What you expected to happen
- What actually happened
- Steps to reproduce the problem
- Your operating system and relevant hardware
- Any useful error messages or screenshots

### Suggest an idea

Feel free to open an issue to discuss a feature or improvement before implementing it. Small ideas and suggestions are welcome, even if you are not planning to write the code yourself.

### Submit code

1. Fork the repository.
2. Create a branch for your changes.
3. Keep changes focused and avoid unrelated modifications.
4. Test your changes where practical.
5. Open a pull request and briefly explain what you changed and why.

For larger changes, please open an issue first so we can discuss the approach.

## Code and style

- Prefer clear, readable, and maintainable C++.
- Keep changes consistent with the existing code.
- Avoid adding dependencies unless they provide a clear benefit.
- Include or update tests when practical.
- Be considerate of performance and resource management in OpenGL code.

These are guidelines, not a demand for perfection. This is a hobby project, and contributions from people who are still learning are welcome.

## Communication

Please be friendly, respectful, and constructive. See [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

Thanks for helping make the project better!
